# 📊 ExcelToJson Converter

엑셀 데이터를 프로그래머가 원하는 형태의 JSON 구조(배열, 맵, 리스트 등)로 손쉽게 파싱할 수 있습니다. Node.js 기반의 핵심 코어를 바탕으로, **웹 브라우저(Web)**와 **Unity 에디터 자동화 툴(Unity)** 환경을 지원합니다.

## 📝 공통 엑셀 작성 및 파싱 가이드

모든 환경(Node, Web, Unity)에서 동일하게 적용되는 엑셀 파싱 룰입니다. 첫 번째 열(A열)에 `#` 기호로 시작하는 앵커를 작성하여 JSON의 구조를 결정합니다.

### 1. 테이블 타입 기호 (JSON 구조 정의)

| 앵커 기호     | 용도      | 설명                                      | JSON 예시                                         |
| :------------ | :-------- | :---------------------------------------- | :------------------------------------------------ |
| `#{이름}{}`   | 단일 객체 | 환경 설정, 전역 변수 등 단일 데이터       | `{ "Config": { "version": "1.0" } }`              |
| `#{이름}{{}}` | 중첩 객체 | ID를 키값으로 가지는 맵, 사전(Dictionary) | `{ "Weapon": { "WPN_01": { "dmg": 10 } } }`       |
| `#{이름}[{}]` | 객체 배열 | 순서가 중요한 리스트 데이터 (스테이지 등) | `{ "Stage": [ { "level": 1 }, { "level": 2 } ] }` |
| `#{이름}{[]}` | 배열 객체 | 특정 컬럼을 묶어 배열 프로퍼티로 만들 때  | `{ "Spawn": { "x": [1, 2], "y": [3, 4] } }`       |

### 2. 컬럼 및 주석 규칙

- **배열화 (`[]`):** 컬럼 헤더 이름 끝에 `[]`를 붙이면, 해당 열의 데이터를 쉼표(`,`) 기준으로 분리하여 배열(Array)로 변환합니다. (예: `Tags[]` -> `fire,heavy` -> `["fire", "heavy"]`)
- **주석 처리 (`!`):** 시트 이름이나 컬럼 헤더 이름이 `!`로 시작하면 변환기에서 해당 시트/열을 무시합니다. (메모, 참고용으로 활용)
