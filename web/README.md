```md
# 🌐 Web Converter

별도의 프로그램 설치나 터미널 조작 없이, 웹 브라우저에서 드래그 앤 드롭으로 엑셀을 JSON으로 변환할 수 있는 프론트엔드 도구입니다.

## 🔗 접속 링크

- [Web Link](https://ryulurala.github.io/ExcelToJson/web/)

---

## 💻 사용 방법

1. 위 링크에 접속합니다.
2. 변환할 엑셀 파일(`.xlsx`)을 화면에 드래그 앤 드롭하거나 파일 선택창을 통해 업로드합니다.
3. 변환된 JSON 결과를 확인하고 필요한 파일을 다운로드합니다.

_(GitHub Pages를 통해 `web/` 폴더가 호스팅되도록 설정되어 있습니다.)_
```
